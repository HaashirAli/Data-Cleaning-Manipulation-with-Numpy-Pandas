# Sunday Project — Sales Data

## Project Description
This project uses Pandas to clean sales data, calculate revenue,
create charts, and perform CSV file updates.

## Files
- `sales_raw.csv` — Original input data
- `cleaned_sales.csv` — Cleaned data with revenue
- `sales_updated.csv` — Updated data with tax and price changes
- `Sunday_Project.ipynb` — Notebook containing Part A and Part B

## How to Run
1. Keep the CSV files and notebook in the same folder.
2. Open the notebook in Jupyter Notebook or Google Colab.
3. Run the notebook cells from top to bottom.
